# 신은영 · DevOps Portfolio

https://gpffh20.github.io/

GitHub Pages로 배포하는 정적 포트폴리오입니다.

## 수정

- 메인 내용: `templates/home.html`
- 프로젝트 상세 내용·공통 레이아웃: `build.py`
- 디자인: `styles.css`
- 이미지 확대·목차: `site.js`
- 이미지와 다운로드: `assets/`

문구를 수정한 후 `python3 build.py`를 실행하고 생성된 HTML과 함께 커밋합니다.
`main` 브랜치 루트에서 GitHub Pages가 배포됩니다. 별도 패키지 설치가 필요하지 않습니다.

Pretendard는 SIL Open Font License로 사용합니다. 라이선스는 `assets/Pretendard-LICENSE.txt`에 있습니다.

이전 개인 홈페이지의 기록은 Git 커밋 이력에 보존되어 있습니다.
