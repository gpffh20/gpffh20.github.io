# UtterAI 기술 포트폴리오 · 신은영

https://gpffh20.github.io/

UtterAI의 서비스 개요, 담당 범위, 전체 아키텍처와 문제 해결 사례 3개를 담은 정적 기술 포트폴리오입니다.

## 수정

- 개요·아키텍처·자료: `templates/home.html`
- 네트워크·오토스케일링·ChatOps 사례: `templates/utterai-cases.html`
- 공통 레이아웃·코드 링크·생성: `build.py`
- 디자인: `styles.css`
- 이미지 확대·목차: `site.js`
- 구성도·그래프·원본 PDF: `assets/`

수정 후 `python3 build.py`를 실행하고 생성된 파일과 함께 커밋합니다.
`main` 브랜치 루트에서 GitHub Pages가 배포됩니다. 별도 패키지 설치가 필요하지 않습니다.

기존 `/projects/utterai/` 주소는 메인으로 이동하며, 사례별 해시 링크도 유지합니다.
이전 포트폴리오의 기록은 Git 커밋 이력에 보존되어 있습니다.

Pretendard는 SIL Open Font License로 사용합니다. `assets/Pretendard-LICENSE.txt`를 참고하세요.
