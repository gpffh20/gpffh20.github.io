01 / DEPLOYMENT OPTIMIZATION

이미지 갱신에 필요한 작업만 수행하기

개선 대상

Terraform 기반 배포 실행 경로에서 이미지 갱신 시 반복되는 준비·검증 작업을 줄였습니다.

수행한 변경

  • Terraform 작업 폴더를 재사용하도록 구성했습니다.
  • 중복 초기화와 검증 작업을 생략해 이미지 갱신에 필요한 실행 경로를 줄였습니다.

02 / CREDENTIAL DESIGN

Agent에 장기 AWS 키를 전달하지 않기

Terraform 인프라 프로비저닝에 SOPS 기반 Zero-Secret 패턴을 적용했습니다. Agent용 ECR 단기 인증 API는 Job 소유권과 lease를 검증한 뒤 인증을 제공하도록 구현해 장기 AWS 키를 Agent에 전달하지 않도록 했습니다.

담당 구현

  • SOPS를 활용한 인프라 비밀 정보 관리 패턴 적용
  • 요청 Agent의 Job 소유권과 lease 검증
  • ECR 접근용 단기 인증 API 구현
03 / MIGRATION VERIFICATION

같은 URL에서 실행 환경까지 확인하기

Cloudflare Origin 연동으로 고정 URL 기반 AWS ↔ On-Prem 전환을 구현하고 검증했습니다. 환경 전환 뒤 서비스 응답, 이미지 digest와 실행 호스트를 대조해 배포 결과를 확인했습니다.
