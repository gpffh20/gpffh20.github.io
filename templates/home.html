PROJECT OVERVIEW

어떤 서비스이고, 무엇을 담당했는가

언어재활사가 치료 세션 녹음을 업로드하면, 발화자를 구분한 전사문과 언어지표를 분석하고 SOAP 형식의 치료 기록 초안을 생성합니다. 치료사는 분석 결과와 초안을 검토·수정해 치료 기록을 완성합니다.

  1. 01치료 녹음 업로드
  2. 02전사·언어지표 분석
  3. 03SOAP 초안 생성
  4. 04치료사 검토·수정
